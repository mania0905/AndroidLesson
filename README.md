# InvoiceFlow - 請求書・見積書作成SaaS

**無料で開発・月額固定収益型**の革新的な請求書・見積書作成サービスです。

## 特徴

- **無料で開発**: Next.js、TypeScript、Tailwind CSS などオープンソース技術のみで構築
- **固定収益モデル**: 月額980円のProプランで確実な recurring revenue
- **バグフリー**: 厳格なTypeScript、ユニットテスト、バリデーション完備
- **Vercel無料枠**: デプロイコストゼロで運用可能

## 技術スタック

- **フレームワーク**: Next.js 14 (App Router)
- **言語**: TypeScript
- **スタイリング**: Tailwind CSS
- **アイコン**: Lucide React
- **テスト**: Vitest + Testing Library

## セットアップ

```bash
npm install
npm run dev
```

開発サーバーは http://localhost:3000 で起動します。

## スクリプト

- `npm run dev` - 開発サーバー起動
- `npm run build` - 本番ビルド
- `npm run start` - 本番サーバー起動
- `npm run test` - ユニットテスト実行
- `npm run lint` - ESLint実行

## 機能

- **請求書・見積書作成**: プロ仕様の書類を簡単作成
- **振る請求（/shake）**: 世界初！スマホを振って送る請求書
  - 3回振ってスタート
  - 声で入力（「5万円」「ウェブ制作」など）
  - 振って送信（振り強さで送信パワー表示）
  - スマホだけで完結する革命的なUX
- **顧客管理**: 顧客情報の登録・編集
- **事業者情報設定**: 請求書に表示する発行元情報
- **ステータス管理**: 下書き→送付済み→入金済みのワークフロー
- **PDF印刷**: ブラウザの印刷機能でPDF出力
