# CABIN

車の同乗中に、役割分担したAIクルーと音声（または文字）で会議し、**動画以外の下書き**をカテゴリ別に埋めるWebアプリのMVPです。

## できること

- AIクルー: 進行役 / Webリサーチャー / 決定者 / 成果物作成者
- 成果物カテゴリ:
  - 決定事項
  - 議事録
  - メモ
  - TODO
  - プレゼン下書き（スライド構成）
  - 画像デザイン下書き（コンセプト・配色・生成プロンプト）
- 音声入力（対応ブラウザのWeb Speech API）
- セッションのMarkdown書き出し

動画生成は対象外です。

## 起動

```bash
npm install
npm run dev
```

```bash
npm run build
```

## 注意

- 運転中の利用は想定していません（同乗・停車時向け）
- 現時点のAI応答はローカルのデモ用パイプラインです。後から実LLM / 画像生成APIへ差し替え可能な構造です
