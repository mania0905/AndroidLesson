# 素マッチ - 見栄を張らないマッチング

## コンセプト

**「お金がなくても、素の自分で付き合える」**

- 見栄を張らなくていい
- 予算を正直に伝えて、価値観の合う人と出会える
- 無料デートでも、500円のコーヒーでも、一緒に楽しめる人を

## 課題の解決

| 課題 | 解決策 |
|------|--------|
| お金がない | 予算レベルでマッチング（無料〜5000円） |
| 見栄を張ってしまう | 「予算〜500円」でOKと明示 |
| 気まずい思いをしたくない | お金の使い方で合う人だけとマッチ |

## 収益モデル（儲かる仕組み）

### 1. プレミアム会員 ¥480/月
- マッチング相手と無制限メッセージ
- 誰がいいねしたか見れる
- 推薦の優先表示
- **14日間無料トライアル**でコンバージョン促進

### 2. プロフィールブースト ¥300/回
- 1日間、推薦の上位に表示
- より多くの人に見てもらえる

### 3. スーパーライク ¥100/回
- 相手に特別通知でアピール
- マッチ率向上の課金

### 4. パートナーシップ（スポット紹介）
- 予算に合うカフェ・イベントの紹介
- 掲載料・紹介料で収益

## ユーザーフロー

1. **オンボーディング** - ニックネーム、予算感、目的、興味を設定
2. **スワイプ** - 推薦された人をいいね/パス
3. **マッチング** -  mutual like で成立
4. **メッセージ** - プレミアム会員のみ
